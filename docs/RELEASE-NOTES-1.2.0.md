# SmartRoutine v1.2.0

## About SmartRoutine

SmartRoutine helps you structure recurring workflows and run them step by step. A routine can consist of different actions, for example opening websites, applications, folders or documents.

Every step can be run manually or automatically, so both simple and complex workflows are supported efficiently.

## Features

* Create and manage your own routines
* Run single steps manually or automatically
* English and German interface (starts in your Windows language, switch any time at the bottom of the routine list)
* Light and dark theme switch in the same bar
* Missing programs, folders or documents are reported before a routine starts
* File and folder dialogs open at the path you already chose
* Double click a routine to edit it
* A routine counts as done only after you finish it
* Clearer error messages, with details saved for troubleshooting

## Installation

1. Download `SmartRoutine.exe`
2. Start it, no installer is needed
3. Updates are detected automatically

## Notes

* On the first start Windows may show the notice "Unknown publisher", because the application is currently not digitally signed.
* All routines and settings are stored locally.
* The embedded browser needs the Microsoft Edge WebView2 runtime, which is part of current Windows versions.
